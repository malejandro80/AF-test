## Summary of Changes

This Pull Request delivers the complete trader-facing frontend interface for the ArrowFin Daily Snapshot Widget.

### 1. High-Density Dark-Mode UI (`frontend/src/components/TraderDailySnapshotWidget.tsx`)
- Built with React / Next.js 15 App Router patterns and Tailwind CSS (`bg-slate-950`, `text-slate-100`, `font-mono`).
- **High-Risk Visual Callout:** Automatically triggers when `riskScore > 75`:
  - Pulsating red warning border (`border-rose-500 animate-pulse`).
  - High-risk alert badge displaying margin utilization percentage.
  - Risk progress gauge color progression (Emerald < 50% $\rightarrow$ Amber 50-75% $\rightarrow$ Rose > 75%).
- **Open Positions Inventory Table:** Real-time table displaying Instrument, Exchange, Long/Short side, Quantity, Avg Entry Price, Mark Price, Point Value, Notional Value, and Unrealized P&L.

### 2. Custom Hooks (`frontend/src/hooks/`)
- `useTraderSnapshot.ts`: Handles initial REST fetch (`/api/v1/snapshot`), loading skeleton state, error retry handling, and tenant selection.
- `useSnapshotStream.ts`: WebSocket hook maintaining real-time stream subscription (`/ws/snapshot`), exponential backoff reconnection, and connection status lifecycle indicators (`CONNECTED`, `CONNECTING`, `RECONNECTING`, `DISCONNECTED`).

### 3. Component States & Dev Tools
- **Loading State:** Animated skeleton loaders preventing layout shifts.
- **Error State:** Dismissible error card with explicit retry action.
- **Empty State:** Clean empty state illustration when an account has no open positions.
- **Live Fill Simulator Button:** Integrated dev action triggering `/api/v1/dev/fills` to test real-time WebSocket push updates live on screen.
