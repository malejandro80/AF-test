## Summary of Changes

This Pull Request delivers the core database schema, data ingestion loader, and daily trader snapshot engine for the ArrowFin trading platform assessment.

### 1. Database Schema (`backend/prisma/schema.prisma` & `backend/src/db.ts`)
- **Explicit Multi-Tenant Scoping:** Added mandatory `broker_id` foreign key and tenant discriminator across `brokers`, `traders`, `accounts`, `instruments`, `market_prices`, and `fills`.
- **Index Optimization Strategy:**
  - `@@index([broker_id, account_id])` on `accounts` and `fills` for $O(1)$ tenant-scoped snapshot queries.
  - `@@index([account_id, filled_at])` for session trade history lookups.
  - `@@index([broker_id, id])` on `traders`.
- **CSV Data Loader:** Automated seeder loading seed data from `dataset/*.csv` into SQLite idempotently.

### 2. Snapshot Calculation Engine (`backend/src/snapshot/snapshotService.ts`)
- **Dataset Cut Time:** Fixed at `2026-08-25T14:30:00Z`.
- **CME Session Window:** Current session start set to `2026-08-24T22:00:00Z`.
- **Realized P&L Engine:** Calculates trade profit/loss for executions closed during current session, accounting for side commissions and contract `point_value_usd` scaling (`ES`=$50, `MES`=$5, `NQ`=$20, `MNQ`=$2, `CL`=$1000, `MCL`=$100, `GC`=$100, `6E`=$125,000).
- **Unrealized P&L Engine:** Marks open net positions against `market_prices` as of cut time.
- **Risk Score Formula:** Implements `min(100, abs(positions_notional) / account_balance * 100)` with `isHighRisk` flag (`riskScore > 75`).

### 3. REST API Routes (`backend/src/routes/snapshotRoutes.ts`)
- `GET /api/v1/snapshot`: Returns broker snapshot or specific account snapshot.
- `GET /api/v1/accounts`: Returns account inventory scoped to caller's `broker_id`.
- `POST /api/v1/dev/fills`: Dev-only fill simulator endpoint.

### 4. Unit Test Suite (`backend/src/snapshot/snapshotService.spec.ts`)
- Tests P&L calculations, risk score formulas, point value multipliers, and multi-tenant isolation enforcement.
