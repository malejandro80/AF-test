## Summary of Changes

This Pull Request introduces all multi-tenant security enforcement layers, automated regulatory PII redaction, formal threat modeling, and security documentation for ArrowFin.

### 1. JWT Tenant Auth Guard (`backend/src/security/jwtAuthGuard.ts`)
- Validates JWT tokens across REST endpoints and WebSocket handshakes.
- Binds request context to verified `broker_id` claim.
- Rejects cross-tenant access attempts with `HTTP 403 Forbidden` (`ERR_TENANT_ACCESS_DENIED`).

### 2. Automated PII Log Redaction (`backend/src/security/piiRedactor.ts`)
- RegEx-based log interceptor scrubbing sensitive customer details from system stdout and cloud aggregators.
- Replaces SSNs, Emails, Phone numbers, Banking ACH/routing details, and S3 KYC URIs with `[REDACTED_*]` tags.

### 3. Comprehensive Security Documentation (`SECURITY.md`)
- Authoritative document detailing:
  1. REST and WebSocket authentication models.
  2. Structural multi-tenant isolation guarantees.
  3. Regulatory PII handling (CFTC Rule 1.31 / NFA Compliance 2-9).
  4. Active threat modeling (IDOR, WebSocket tenant spoofing, log injection, dev endpoint gating).
  5. Production hardening recommendations (KMS column encryption, Redis rate limiting, PostgreSQL RLS, Immutable WORM audit trails).

### 4. Task 4 Senior Team Lead Code Review
